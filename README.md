# 🍋 Little Lemon Restaurant App (Capstone Project)

This is a responsive front-end web application for **Little Lemon**, a fictional Mediterranean restaurant. The app allows users to browse the menu, make table reservations, and place orders—all built using React.js.

---

## Live Demo

_Not deployed yet._ You can run it locally by following the instructions below.

---

## Features

- Multi-page routing with React Router
- Menu with featured specials
- Place an order with "Order a Delivery" buttons
- Table reservation with available time logic
- Unit-tested reducer for time slot availability
- Fully responsive layout

---

## Getting Started

### Prerequisites

- Node.js and npm installed

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/littlelemon.git

# Navigate into the project directory
cd littlelemon

# Install dependencies
npm install

# Start the development server
npm start
